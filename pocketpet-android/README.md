# Pocket Pet (Android, full edition)

The Pocket Pet game page (`app/src/main/assets/pet.html`, `?edition=full`) in a full-screen WebView, plus a
notification when the pet calls while the app is closed (the page computes the next call and asks the app to set
an alarm through `PetAndroid.schedule`). The same page runs inside the Unicorn Clock as the easier Fire edition.
