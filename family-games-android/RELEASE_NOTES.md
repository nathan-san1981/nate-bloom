Family Games: one button that puts the tablet games on an Android tablet (made for the Galaxy Tab S10 FE+).
Installs Pocket Pet (the classic edition) and OpenTTD (the full game with touch controls). Android asks
"Do you want to install this app?" once per game; tap Install.

On the tablet: download FamilyGames.apk below, open it, Install (if asked, allow your browser to install apps),
open Family Games, tap "Install the games". On a Samsung with Auto Blocker on, switch it off first
(Settings → Security and privacy → Auto Blocker) and back on afterwards.
